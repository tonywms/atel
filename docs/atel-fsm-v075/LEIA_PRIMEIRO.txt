ATEL FSM V07.5 - FASE 1 / PREPARACAO
Este pacote instala no projeto apenas documentos, SQL de referencia e diagnostico.
Nao ativa sincronizacao. Nao altera dados, OS, estoque ou Supabase.
O SQL utiliza RLS por usuario autenticado, NAO compartilhamento por empresa.
Para sincronizar coletor e admin em usuarios distintos sera necessario modelo de tenant e permissoes.
NAO executar o SQL em producao antes da revisao de autenticacao e tenant.
Proxima fase requer package.json, configuracao de autenticacao (sem segredos) e modelo de tenant.
